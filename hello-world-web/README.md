# 🌍 Hello World Web Project

Un projet web simple et élégant pour commencer votre aventure dans le développement web.

## ✨ Fonctionnalités

- 🎨 Design moderne et responsive
- ⚡ Interface interactive avec JavaScript
- 📱 Compatible mobile et desktop
- 🚀 Serveur HTTP intégré
- 💫 Animations CSS fluides

## 🚀 Comment démarrer

### Option 1: Serveur Python (Recommandé)
```bash
cd hello-world-web
python3 server.py
```

### Option 2: Serveur HTTP simple
```bash
cd hello-world-web
python3 -m http.server 8000
```

### Option 3: Node.js (si installé)
```bash
cd hello-world-web
npx serve .
```

## 🌐 Accès au site

Une fois le serveur démarré, ouvrez votre navigateur et allez à :
- **http://localhost:8000**
- **http://127.0.0.1:8000**

## 📁 Structure du projet

```
hello-world-web/
├── index.html      # Page principale
├── style.css       # Styles CSS
├── server.py       # Serveur HTTP Python
└── README.md       # Ce fichier
```

## 🛠️ Technologies utilisées

- **HTML5** - Structure de la page
- **CSS3** - Styles et animations
- **JavaScript** - Interactivité
- **Python** - Serveur HTTP

## 🎯 Fonctionnalités interactives

- Bouton "Cliquez ici!" avec messages aléatoires
- Horodatage en temps réel
- Design responsive qui s'adapte à tous les écrans
- Animations fluides au survol et au clic

## 🎨 Personnalisation

Vous pouvez facilement personnaliser :
- Les couleurs dans `style.css`
- Le contenu dans `index.html`
- Les messages dans le script JavaScript
